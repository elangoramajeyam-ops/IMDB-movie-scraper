# 🎬 IMDb Movie Scraper

## 📌 Project Description
The IMDb Movie Scraper is a Python-based web scraping project that collects information about the IMDb Top 250 movies using Selenium and Chrome WebDriver. It extracts essential movie details, including rank, title, release year, and IMDb rating, and stores the collected information in a CSV file for easy access and analysis.

## 🎯 Objectives
- Extract movie details automatically from IMDb.
- Collect movie rankings, titles, release years, and ratings.
- Store the scraped data in CSV format.
- Demonstrate web scraping using Python and Selenium.
- Organize movie data for further analysis.

## 🛠️ Technologies Used
- **Python** – Programming language
- **Selenium** – Web browser automation and scraping
- **Pandas** – Data organization and CSV file handling
- **Chrome WebDriver** – Browser automation

## ✨ Features
- Scrapes IMDb Top 250 movie information.
- Extracts movie rank, title, year, and rating.
- Saves the results into a CSV file.
- Automates data collection using a web browser.
- Provides structured data for further analysis.

## ⚙️ Installation

Install the required libraries:

```bash
pip install selenium pandas webdriver-manager
```

## ▶️ How to Run

Run the Python script:

```bash
python imdb_scraper.py
```

## 📂 Output
The scraped movie information is saved in a CSV file, which can be opened using Microsoft Excel, Google Sheets, or Python for further analysis.
